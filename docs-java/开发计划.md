## 2. Phase 0: 基础框架搭建 (24h)

- **内容**：

## 6. 风险项与缓解

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|---------|
| Spring Cloud 学习曲线 | 开发周期延长 | 中 | 先用 Spring Boot 单体，后期拆分 |
| Milvus Java SDK 兼容性 | RAG功能受限 | 低 | 备选 InMemoryVectorStore |
| 流式响应复杂度 | SSE对接困难 | 中 | 优先用 SseEmitter，备选 WebSocket |
| Python 推理模型调用 | 跨进程通信开销 | 中 | ProcessBuilder + 共享文件系统 |
| 微服务拆分过早 | 开发效率降低 | 高 | **Phase 0-2 用单体，Phase 3 拆分** |
| 外部API费用 | 运营成本 | 低 | 优先使用本地模型 + Edge-TTS |
| GPU资源不足 | 唱歌/视频/换脸不可用 | 高 | 云API降级(Sora/Wanx) + Mock引擎 |
| DeepFake合规风险 | 法律风险 | 中 | 强制水印+使用协议+内容审核+审计日志 |
| 视频生成耗时长 | 用户体验差 | 中 | WebSocket进度推送+任务队列+超时处理 |
