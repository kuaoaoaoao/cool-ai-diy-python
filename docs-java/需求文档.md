## 1. 项目概述

### 1.1 项目背景

基于已完成的 Python 版 CoolAI 平台，使用 Java 技术栈进行重构开发。Java 版本在保留所有功能的基础上，重点优化以下方面：

- **架构升级**：从单体 FastAPI 升级为 Spring Boot 微服务架构
- **企业级特性**：更强的并发处理、事务管理、安全体系
- **可维护性**：接口化设计、依赖注入、AOP 切面
- **可扩展性**：消息队列解耦、分布式缓存、服务注册发现

### 1.2 与 Python 版本的对比优化

|| 维度 | Python版 | Java版（优化） |
|------|---------|--------------|
| 框架 | FastAPI 单体 | Spring Boot + Spring Cloud 微服务 |
| 异步任务 | BackgroundTasks（进程内） | RabbitMQ 消息队列（跨进程） |
| 缓存 | 无缓存层 | Spring Cache + Redis 多级缓存 |
| 安全 | JWT + bcrypt（手写） | Spring Security + OAuth2 + JWT |
| 配置 | Pydantic Settings | Spring Cloud Config + Nacos |
| 数据库 | async SQLAlchemy | MyBatis-Plus + JPA |
| 监控 | Prometheus 直出 | Micrometer + SkyWalking 链路追踪 |
| 文档 | Swagger 自动 | SpringDoc OpenAPI 3.0 |
| 测试 | pytest | JUnit 5 + Mockito + TestContainers |

## 3. 非功能需求

|| 类别 | 要求 |
||-----|------|
